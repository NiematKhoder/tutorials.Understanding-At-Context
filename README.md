# Dihydro Data Model @context Generator

This repository is a fork of the original repository from [satrai-lab/di-hydro-data-models](https://github.com/satrai-lab/di-hydro-data-models/tree/main/static). I used the tool provided there to create the `@context` file for the Dihydro Data Model. In addition, the markdown documentation was generated from the YAML file I created.

## Overview

This project leverages a tool that runs on Linux to automate the generation of context files for the Dihydro Data Model. It simplifies the documentation process by converting a YAML configuration into well-structured markdown.

## System Requirements

- **Operating System:** Linux (Tested on Ubuntu 24.04 and also compatible with Ubuntu 22.04)
- **Dependencies:** Refer to the original repository’s documentation for a complete list of dependencies.
